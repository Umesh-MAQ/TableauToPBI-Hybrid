# Validation workbook: writes the single Excel validation workbook
# (Summary / Visual Mapping / Measure Validation / Filter Validation /

# engine remains standard-library only.

# .twb (stdlib base64/zipfile — no extra deps); the Power BI pane is a real
# Power BI Desktop capture the user drops into validation/screenshots/.
Pillow>=10.0
